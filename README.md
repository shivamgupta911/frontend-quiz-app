#React quiz app

this is a simple quiz app built using react.

## features 
- 4 MCQ
- SCORE TRACKING
- 15 SEC TIMER FOR EACH QUES
- AUTOMATIC MOVE TO NEXT QUESTION WHEN TIME RUNS OUT
- RESULT SCREEN AT END
- RESTART QUIZ OPTION

  ## CONCEPTS USED

  -RREACT COMPONENTS
  -useState
  -useEffect
  -props

  ##to run
  1. clone the repo
  2. git clone<repository-link>

  npm install

  npm run dev
